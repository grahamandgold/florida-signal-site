# Florida Signal logo and avatar kit

Approved digital brand exports assembled on August 16, 2026.

## Canonical mark

The three files in `sources/` are the cleanest original artwork currently available:

- `mark-full-color.png` — primary navy Florida mark with blue and aqua building forms.
- `mark-white.png` — reverse mark for dark backgrounds and photography.
- `mark-navy-mono.png` — one-color mark for print and low-detail reproduction.

Each source is a transparent 791 × 783 PNG. The emblem geometry is a signature element: do not redraw it, add an arrow, stretch it, recolor individual shapes, or merge it with an action icon.

## Ready-to-use exports

- `logos/` — horizontal, compact and stacked lockups for light and Atlantic-navy backgrounds.
- `production-hires/` — the production 2510/5020 px horizontal and compact lockups, 2892 px
  stacked lockups, exact source emblems and the authoritative high-resolution export manifest.
- `avatars/` — square and circle-safe social/profile artwork from 32 px through 1024 px.
- `symbol/` — transparent full-color, white and navy emblem exports.
- `EXPORTS.md` — file-by-file use guidance from the export package.
- `source-package/` — both corrected Claude Design downloads preserved unchanged, including
  `florida-signal-production-hires-lockups-2026-08-16.zip`.
- `VECTOR_MASTER_BRIEF.md` — the production and acceptance specification for the future SVG/AI master.

The website header uses `production-hires/fs-lockup-horizontal-transparent-2510.png` with the
5020 px file as its `srcset` high-density tier. The footer uses the matching compact 2510/5020 px
pair. Keep the older `logos/` exports for compatibility, but do not use them for the production
masthead. Use the compact lockup where “Development Intelligence” would become too small to read.

## Verification

Codex visually inspected every production-hires light/dark, compact, horizontal and stacked lockup.
All PNGs decode correctly; dimensions match `production-hires/EXPORTS.md`; transparent variants
have a genuine alpha channel; navy variants are fully opaque; and the included source emblems are
byte-for-byte identical to the canonical originals. The emblem matches the original source artwork
and contains no added arrow.

The 2510/5020 px production lockups are suitable for the website at Retina and 3× mobile density.
A true SVG, AI or EPS master has not been located; obtain one before billboard, vehicle-wrap or
other large-format print work. No traced or substitute SVG is included.
